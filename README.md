# Fioverr

Een responsive HTML/CSS/JavaScript-versie van de aangeleverde Fioverr-screenshot.

## Bestanden
- `index.html` — pagina-inhoud
- `style.css` — vormgeving en responsive layout
- `script.js` — interactie voor de serviceknoppen en opdrachtformulier
- `assets/` — uit de screenshot uitgesneden afbeeldingen

## Lokaal bekijken
Open `index.html` in je browser. Er is geen buildstap of framework nodig.

## Publiceren op GitHub Pages
1. Maak een nieuwe GitHub-repository.
2. Upload alle bestanden en de map `assets` naar de hoofdmap van de repository.
3. Ga naar **Settings → Pages**.
4. Kies **Deploy from a branch**, selecteer `main` en `/ (root)`, en sla op.

## Nog aanpassen
- Vervang in `script.js` `jullie-email@voorbeeld.nl` door jullie echte contactadres.
- De afbeeldingen zijn crops uit de aangeleverde screenshot. Gebruik bij voorkeur de originele afbeeldingen als jullie die hebben.
- Pas de teksten en eventuele contactgegevens in `index.html` aan.
